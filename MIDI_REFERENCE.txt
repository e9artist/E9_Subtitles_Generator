KEYBOARD SHORTCUTS
------------------
SPACE   advance (commit + advance)
B       blank screen and advance
Y       curtain: blank the screen while held; restore on release.
        Does NOT advance. Works in any preset, including mid-stanza.
Shift+Y toggle on-screen reference
1-4     preset: 1=SimpleLine, 2=WordHighlight, 3=KaraokeFill, 4=WordReveal
F       transition: none / fade / grow
G       transition duration: 0.3 / 0.6 / 1.0 s
J       highlight: box / outline / bold / grow
K       accent color (cycles through the accent palette)
C       font color (cycles through the font-color palette)
L       size (cycles through presets)
N       font (cycles through fonts folder)
U       word fade duration: 0.0 / 0.2 / 0.5 / 1.0 s
P       capture current state as home snapshot
R       reset to line 0
O       open audio file
ENTER   start / stop recording (manual start plays the count-in)
S       save timestamps file
X       export as MIDI file
+ / -   BPM up / down
] / [   count-in beats up / down
M       Record mode:  save timestamps and render video.
        Render mode:  return to Record mode.
H       toggle help panel

Note on the curtain (Y):
  Y is a momentary toggle, not an advance. While held, the screen is
  transparent. On release, the previous display state is restored
  (current line, word, preset, and modifiers). Unlike B, nothing in
  the lyrics advances. This makes it useful for "flashing" a single
  line of text against a dark or empty background, and it works in
  any preset without disturbing the take. Both the press and the
  release are recorded as separate events when a take is running,
  and both are written into the exported MIDI (see notes 39 and 40
  below).

LYRICS FILE FORMAT
------------------
Each line in lyrics.txt is one "content line" unless it is a marker.

Markers (each on its own line):
  [stanza]       start a multi-line stanza block
  [endstanza]    end a multi-line stanza block
  [emptyline]    inside a stanza: renders as empty vertical space.
                 The recorder skips it — no tap needed.
                 Using [emptyline] outside a stanza is a warning and ignored.
  [blank]        clears the screen, is its own single-line stanza,
                 and the recorder lands on it (SPACE advances past it).
                 Using [blank] inside a [stanza] block is a syntax warning;
                 the stanza auto-closes there.

Anything outside [stanza] / [endstanza] is treated as single-line stanzas,
one per line.

Behavior summary:
  - SimpleLine advances one whole stanza per tap.
  - WordHighlight / KaraokeFill / WordReveal advance one word per tap,
    then one line within the stanza, then to the next stanza.
  - The transition (fade/grow) applies to the whole stanza block at once.
  - The word fade applies to the newest word only.
  - The curtain (Y) is independent of all of the above and never
    advances the position.

CC NUMBERS
----------
20      Transition type (0=none, 1=fade, 2=grow)
21      Transition duration (0=0.3s, 1=0.6s, 2=1.0s)
22      Highlight style (0=box, 1=outline, 2=bold, 3=grow)
23      Accent color (palette index 0-127)
24      Size (0-127, maps to 12-200px)
25      Font index (0 = Default, then fonts in data/fonts/ alphabetical)
26      Position X (0-127, 64 = center)
27      Position Y (0-127, 64 = center; ~90 places text near bottom)
28      Word fade duration (0-127, maps to 0.0 - 2.0 seconds)
29      Font color (palette index 0-127)

CCs take effect immediately in the sketch, whether the DAW is playing
or stopped. Repeats of the same value are still processed (the sketch
doesn't dedupe), so if a DAW resends a value on stop, it will overwrite
the pending state. Use P to re-snapshot the home state if this happens.

COLOR PALETTE (CC 23 and CC 29)
-------------------------------
Both accent color (CC 23) and font color (CC 29) index into the same
128-entry color palette. The palette is generated at startup and
covers a wide range of colors — not just a saturated hue wheel.

Layout (approximate):
  0-15      whites and grays, from pure white down to near-black
  16-31     saturated hues at full brightness (16 hues around the wheel)
  32-47     pastels of the same 16 hues
  48-63     deep jewel tones
  64-79     muted / earthy tones
  80-95     neon
  96-111    tinted neutrals
  112-127   dark grays down to pure black

Useful anchors:
  CC 0    pure white
  CC 16   red
  CC 20   yellow
  CC 24   cyan
  CC 127  pure black

Defaults:
  Font color starts at 0 (white).
  Accent color starts at 16 (red).

The keyboard cycles (K for accent, C for font color) walk through a
short list of palette indices rather than all 128 — that list lives
in ACCENT_CYCLE and FONT_COLOR_CYCLE near the top of the sketch, and
is easily edited. The first entry of each array is the default value
for that role.

MIDI ROUND TRIP
---------------
1. Record a performance with the keyboard or MIDI.
2. Press X to export the take as a .mid file.
   (You do NOT have to save timestamps for the MIDI export to work.)
3. Load the .mid into your DAW to edit timing, CCs, or notes.
4. Route the DAW's MIDI output to the sketch's input device.
5. Play the DAW. The sketch replays the visuals in sync.
6. If MIDI notes 34/35 (see below) were left in and the whole .mid file
   was played a new timestamp take is recorded and can be saved/rendered.

The exported MIDI includes:
  - Note 34 at the top to start recording immediately
  - Note 37 to reset to line 0
  - CC messages for every modifier that changes during the take
  - Preset notes (48-51) one tick before each advance
  - Advance notes (38) at each event's time
  - Curtain notes (39 down, 40 up) at their recorded times
  - Note 35 to stop recording three seconds after the last event

TIMESTAMPS FILE FORMAT
----------------------
One event per line, pipe-separated:

  time|preset|action|line|word|transition|transDur|hiliteStyle|accent|size|font|posX|posY|wordFade|visible|fontColor

The final column, `visible`, controls the curtain:
  1 = show (normal)
  0 = blank (curtain down)

Curtain events use action strings "curtainOff" and "curtainOn" so the
column is self-documenting in the file, but `visible` is the field the
renderer actually honors.

Older files with fewer fields still load. Missing trailing fields
default to sensible values. Older timestamp files without the
`visible` column are treated as fully visible (visible=1), so they
render as they did before the curtain feature was added. Files
without the trailing `fontColor` column default to 0 (white), which
is the current default font color.

Note that the `accent` column was formerly named `color` and, before
that, held a hue-wheel value rather than a palette index. If you
have very old timestamps files, their color values will map to
different colors under the new palette. Re-rendering old takes may
require manually adjusting this column, or just re-recording.

PRO TIPS
--------
- Press P to lock the current state as the "home" snapshot that R and
  the MIDI STOP command restore to. The home snapshot is also captured
  automatically at the start of every recording.
- Pressing M saves timestamps (overwriting the previous file for the
  same audio) and renders. If you want to save without rendering,
  press S.
- If there is a timestamps file from a previous session in the sketch
  folder and you press M before recording a take, the program will
  use that timestamps file for rendering.
- Word fade is per-event. Set it before tapping SPACE, and the fade
  applies to that event's newest word. Fades are also written into
  the exported MIDI as CC 28.
- Font color and accent color are independent. A white font with a
  red accent is the default look. If you set the font to black for
  a light background, you may want to bump the accent to something
  bright (yellow, cyan) so highlights stay readable. Both values
  are recorded per-event and round-trip through the MIDI export.
- SimpleLine and word-based classes advance differently. This is
  intentional: SimpleLine jumps whole stanzas, word-based classes
  walk word-by-word through each line in a stanza before replacing it.
- The curtain ignores transitions and word fades. It snaps to
  transparent on press and snaps back on release, regardless of the
  current transition / word-fade settings. This is by design — the
  curtain is meant to be an instant "flash," not an animated one.
- The curtain is a no-op while the screen is already blanked with B.
  B owns the blank state until the next advance; Y does not interfere
  with it, and no curtain events are recorded while B-blanked.

LINUX MIDI SETUP
----------------
See the header comment at the top of the Processing sketch. The short
version: run `sudo modprobe snd-virmidi midi_devs=1`, then `aconnect`
to route Reaper (or whatever DAW) into VirMIDI, and THEN launch
Processing. If you launch Processing first, quit it and re-run the
aconnect step, because Java opens the raw MIDI device at startup and
won't see routes created after that.
